# 飞智 BS2 / BS2 Pro 压风式散热器轻量化控制软件设计规格说明书

- **日期**：2026-10-21
- **版本**：1.0.0
- **目标**：彻底替代原厂飞智空间站 3.0，实现常驻内存 <30MB、永不退后台、开机自愈静默重连、支持实时温控变频与全功能设置的独立轻量化桌面工具（支持托盘常驻与深色控制面板）。

---

## 1. 背景与核心问题

原厂飞智空间站 3.0 基于重型 .NET WPF 架构构建，常驻内存占用超过 400MB，且后台托盘服务存在稳定性缺陷：
1. 最小化到托盘后经常不定时闪退或挂起。
2. 蓝牙断连后无法可靠自愈重连。
3. 一旦与控制软件断连，BS2 Pro 压风式散热器将丧失温度自适应变频能力，回退到机身固定按键档位，严重影响散热效能与噪音体验。

本项目通过逆向提取飞智空间站 3.0 内部对 BS2 Pro 的完整控制协议，构建一个纯净、高效、稳定、可自由定义温控曲线的独立桌面小工具。

## 2. 硬件控制协议规格 (Reverse-Engineered Protocol)

### 2.1 蓝牙 GATT 接口
- **广播名称识别**：`Flydigi BS2`（兼容器件名：`Flydigi BS1`）
- **主服务 Service UUID**：`0000FFF0-0000-1000-8000-00805F9B34FB` (`0xFFF0`)
- **写入特征 Write UUID**：`0000FFF2-0000-1000-8000-00805F9B34FB` (`0xFFF2`, Write Without Response / Write)
- **通知特征 Notify UUID**：`0000FFF1-0000-1000-8000-00805F9B34FB` (`0xFFF1`, Notify)

### 2.2 报文帧封装结构
所有通信数据包遵循以下定长/变长格式：
```
+---------+---------+---------+--------+------------------+----------+
| Header0 | Header1 |  CmdId  | Length |     Payload      | Checksum |
|  0x5A   |  0xA5   | (1 Byte)|(1 Byte)| (Length-3 Bytes) | (1 Byte) |
+---------+---------+---------+--------+------------------+----------+
```
- **帧头**：固定 `0x5A, 0xA5`
- **CmdId**：命令字（1 字节）
- **Length**：从 CmdId 到 Checksum 的总字节数，即 `1 (CmdId) + 1 (Length) + len(Payload) + 1 (Checksum) = len(Payload) + 3`
- **Checksum**：校验和，计算从 CmdId 到 Payload 最后一字节的逐字节无符号和低 8 位：
  $$\text{Checksum} = \left( \text{CmdId} + \text{Length} + \sum_{i} \text{Payload}[i] \right) \pmod{256}$$

### 2.3 指令映射集 (Command Set)

| 功能项 | CmdId | Payload 描述 | 方向 | 报文示例 (Hex) |
|:---|:---:|:---|:---:|:---|
| **查询固件版本** | `0x01` | 无 | PC $\to$ 设备 | `5A A5 01 03 04` |
| **查询快充供电模式** | `0x07` | 无 (回包: 1=5V, 2=9V, 3=20V PD) | PC $\leftrightarrow$ 设备 | `5A A5 07 03 0A` |
| **通电自启开关** | `0x0C` | `[0x01]`(开) / `[0x00]`(关) | PC $\to$ 设备 | 开: `5A A5 0C 04 01 11` / 关: `5A A5 0C 04 00 10` |
| **智能启停模式** | `0x0D` | `[0x00]`(关), `[0x01]`(即时), `[0x02]`(延时) | PC $\to$ 设备 | 即时: `5A A5 0D 04 01 12` |
| **设置转速 (实时)** | `0x21` | `[RPM_Low, RPM_High]` (小端 16位 uint) | PC $\to$ 设备 | 设为 1500 RPM: `5A A5 21 05 DC 05 07` |
| **查询当前与目标转速** | `0x22` | 无 (回包: `[Cur_L, Cur_H, Tgt_L, Tgt_H]`) | PC $\leftrightarrow$ 设备 | 查: `5A A5 22 03 25` |
| **启动智能接管** | `0x23` | 无 | PC $\to$ 设备 | `5A A5 23 03 26` |
| **退出智能接管** | `0x24` | 无 | PC $\to$ 设备 | `5A A5 24 03 27` |
| **模式与转速设置** | `0x26` | `[Mode (1B), Speed_L, Speed_H]` | PC $\to$ 设备 | `5A A5 26 06 04 DC 05 ...` |
| **智能灯效模式随动** | `0x44` | `[0x00~0x05]` (随动档位色) | PC $\to$ 设备 | 档位1: `5A A5 44 04 01 49` |
| **RGB 灯光开关** | `0x46` | `[0x01]`(开) / `[0x00]`(关) | PC $\to$ 设备 | 开: `5A A5 46 04 01 4B` |
| **档位指示灯开关** | `0x48` | `[0x01]`(开) / `[0x00]`(关) | PC $\to$ 设备 | 开: `5A A5 48 04 01 4D` |

## 3. 软件分层架构设计

软件采用解耦的四层模块化设计，运行于 Python 3.13 运行环境：

```
+-----------------------------------------------------------------+
|                       UI 表现层 (Presentation)                   |
|  - CustomTkinter 现代深色仪表盘面板 (主窗口)                       |
|  - Pystray 系统托盘常驻组件 (右下角图标、悬停提示、快捷右键菜单)    |
+-----------------------------------------------------------------+
                               |
                               v
+-----------------------------------------------------------------+
|                     核心控制层 (Core Service)                    |
|  - TemperatureService: CPU/GPU 硬件温度实时采集与多核平滑加权     |
|  - CurveEngine: 静音/性能/自定义 8 节点曲线插值与滞后防抖算法     |
|  - ConfigManager: JSON 配置文件读取与持久化保存                 |
+-----------------------------------------------------------------+
                               |
                               v
+-----------------------------------------------------------------+
|                   蓝牙通信通信层 (BLE Worker)                    |
|  - BleakClient 异步非阻塞调度                                    |
|  - 自动扫描发现 "Flydigi BS2" / "Flydigi BS1"                   |
|  - 守护重连循环 (睡眠唤醒、距离过远、电源重启毫秒级自动重连)      |
+-----------------------------------------------------------------+
                               |
                               v
+-----------------------------------------------------------------+
|                      协议驱动层 (Protocol Engine)                |
|  - BS2Protocol: 帧头封装、校验和计算、报文编解码器                |
+-----------------------------------------------------------------+
```

## 4. 关键功能与算法设计

### 4.1 温度采集与平滑算法
- **数据源**：
  - 优先调用内置的轻量硬件传感器模块（通过 LibreHardwareMonitorLib / OpenHardwareMonitor / Windows 核心温度传感器接口）。
  - 自动读取当前 CPU Package 温度与独立 GPU 核心温度。
- **温度综合值**：
  $$T_{\text{target}} = \max(T_{\text{CPU}}, T_{\text{GPU}})$$
- **滞后滤波 (Hysteresis / Anti-Jitter)**：
  为了避免风扇在临界温度时频繁忽快忽慢，引入 **2 秒移动平均与 2°C 降温滞后窗口**（升温响应迅速，降温缓慢平滑回落）。

### 4.2 曲线引擎 (Curve Engine)
- **供电功率自适应**：
  连接成功后立即通过 `0x07` 查询快充电压模式：
  - 5V 模式：上限锁为 2700 RPM。
  - 9V 模式：上限锁为 3300 RPM。
  - 20V 模式：上限拉满 4000 RPM（最低 1300 RPM）。
- **三种工作模式**：
  1. **静音模式**：1300 ~ 3300 RPM 线性平缓曲线。
  2. **性能模式**：1700 ~ 4000 RPM 激进曲线，60°C 以上快速上拉至最高。
  3. **自定义模式**：用户自由拖动 30°C, 40°C, 50°C, 60°C, 70°C, 80°C, 90°C, 100°C 对应的转速档位，自动通过分段线性插值计算任意摄氏度下的精准目标 RPM。
  4. **固定转速模式**：直接锁定指定档位（1~4 档）或固定设定转速。

### 4.3 蓝牙守护与自愈逻辑
1. 启动时启动 Background Worker 协程，静默搜索目标设备。
2. 连接成功后：
   - 自动下发 `0x23` 启动智能托管模式。
   - 同步配置状态（通电自启、档位灯开关、智能启停设置、灯效模式）。
   - 启动 1 秒心跳循环：发送温度/转速调节指令，读取实际回传转速。
3. 发生异常断开（设备断电、信号中断、系统休眠）：
   - 捕获 `BleakError` / `Disconnected` 事件，UI 状态更新为“搜索重连中...”。
   - 后台以 3 秒间隔指数退避持续尝试重连，连接恢复后自动重新同步托管状态，无需用户重启软件。

### 4.4 用户界面 (UI) 与交互规格
- **设计风格**：与飞智原版一致的深色现代主题（黑底、霓虹蓝/橙渐变）。
- **主界面左侧**：
  - 半圆环温度/转速仪表盘。
  - 大字号实时设备温度（如 `41°C`）。
  - 状态指示：“当前在 智能变频 / 固定转速”。
  - 实时转速读数（如 `1300rpm`）。
- **主界面右侧**：
  - 最大超频转速指示标签（根据读取供电显示绿字 `4000rpm`）。
  - 散热模式切换按钮组（智能变频 vs 固定转速）。
  - 智能变频模式下拉选框（静音模式 / 性能模式 / 自定义模式）。
  - 曲线编辑区（支持节点编辑与平滑曲线预览）。
  - 档位灯显示开关（Switch 开/关）。
  - 灯光模式选择（智能随动、常亮、呼吸、关闭）。
  - 智能启停选择（即时运行、延时、关闭）。
  - 通电自启开关（Switch 开/关）。
- **系统托盘**：
  - 点击窗口右上角“关闭”按钮默认隐藏至右下角系统托盘。
  - 托盘鼠标悬浮提示：`飞智 BS2 Pro [已连接] | 温度: 42°C | 转速: 1450 RPM`。
  - 托盘右键菜单项：
    - `打开控制面板`
    - `模式切换: 静音 / 性能 / 固定 / 智能`
    - `档位灯: 开 / 关`
    - `开机自启`
    - `退出`

## 5. 项目结构与交付文件规划

所有代码置于工作区 `d:\py\REA_Q-Dir\flydigi_bs2_controller\` 下（或同名独立目录）：

```
flydigi_bs2_controller/
├── core/
│   ├── protocol.py          # 报文封装、解包、校验和算法
│   ├── ble_worker.py        # Bleak 蓝牙异步连接与自愈守护
│   ├── sensor.py            # CPU / GPU 实时温度传感器读取
│   ├── curve_engine.py      # 温控曲线计算与插值引擎
│   └── config.py            # 本地配置文件持久化管理 (config.json)
├── ui/
│   ├── app.py               # CustomTkinter 现代控制面板主界面
│   ├── widgets.py           # 仪表盘、曲线绘制控件
│   └── tray.py              # 系统托盘图标与右键菜单
├── main.py                  # 程序主入口
└── requirements.txt         # 核心依赖清单 (bleak, customtkinter, pystray, pillow 等)
```

## 6. 验证与测试标准

1. **协议层单元测试**：
   - 验证各命令字封装输出字节与飞智官方逆向结果 100% 吻合。
   - 验证校验和计算正确性。
2. **连接稳定性测试**：
   - 模拟散热器电源拔插，测试后台断线 5 秒内自动重新捕获并建立连接。
   - 验证睡眠唤醒后自动恢复智能变频调速。
3. **性能指标**：
   - 内存占用：常驻内存 $\le 35\text{MB}$。
   - CPU 占用：每秒轮询时 CPU 波动 $\le 0.3\%$。
